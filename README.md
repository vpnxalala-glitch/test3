# Night Shop — Part 1

Godot 4 low-poly 3D shop blockout.

## Included
- Procedural floor, three walls, two shelf rows, placeholder colored boxes and checkout counter.
- Directional light, shadows and ambient environment.
- Android export preset (arm64, debug build).
- GitHub Actions workflow that validates the project, exports a debug APK, uploads it as an artifact and publishes/updates the `debug-latest` GitHub Release.

## Build status
Open the **Actions** tab in this repository and select **Build Android Debug APK**.
